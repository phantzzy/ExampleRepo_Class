# 🐍 Python Piemērs

Vienkāršs Python projekts, lai iemācītos izmantot Git un GitHub.

## 📁 Projekta struktūra

```
ExampleRepo/
├── README.md          # Projekta apraksts
├── main.py            # Galvenā programma
├── calculator.py      # Kalkulatora funkcijas
├── .gitignore         # Git ignorējamie faili
└── requirements.txt   # Python atkarības
```

## 🚀 Kā palaist

```bash
python main.py
```

## 📚 Git komandas iesācējiem

### Sākuma iestatīšana
```bash
git init                    # Inicializē jaunu repozitoriju
git config user.name "Tavs Vārds"
git config user.email "tavs@epasts.lv"
```

### Ikdienas darbs
```bash
git status                  # Rāda izmaiņu statusu
git add .                   # Pievieno visas izmaiņas
git commit -m "Apraksts"    # Saglabā izmaiņas
git log                     # Rāda vēsturi
```

### Darbs ar GitHub
```bash
git remote add origin URL   # Pievieno attālo repozitoriju
git push -u origin main     # Augšupielādē uz GitHub
git pull                    # Lejupielādē izmaiņas
git clone URL               # Klonē repozitoriju
```
